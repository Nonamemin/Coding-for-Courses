================ auto 地址行为验证 ================

[1] 类型同一性（编译期 static_assert 已保证，编过即成立）
  is_same<decltype(4), int>                     = true
  is_same<decltype(2.98), double>               = true
  is_same<decltype(g_lit), const char*>         = true
  is_same<Box<decltype(4)>, Box<int>>           = true

[2] 对象的大小 / 对齐：auto 版 与 显式版 逐项相同
  int    : auto sizeof=4 alignof=4  |  显式 sizeof=4 alignof=4
  浮点   : auto sizeof=8 alignof=8  |  显式 sizeof=8 alignof=8
  字符串 : auto sizeof=8 alignof=8  |  显式 sizeof=32 alignof=8   <-- auto 推成 const char*，所以大小不同（类型本来就不同）
  char   : auto sizeof=1 alignof=1  |  显式 sizeof=1 alignof=1
  [PASS] auto(int) 与 int 大小相同
  [PASS] auto(int) 与 int 对齐相同
  [PASS] auto(2.98) 与 double 大小相同
  [PASS] auto('c') 与 char 大小相同
  [PASS] auto("Input") 与 string 大小【不同】—— 因为类型不同
  [PASS] auto(double) 地址按 8 字节对齐
  [PASS] auto(const char*) 地址按 8 字节对齐

[3] 同一栈帧内的槽位间距
  auto  a,b,c       间距 = 4, 4
  int   a,b,c       间距 = 4, 4
  mixed auto/int 混写 间距 = 4, 4, 4
  [PASS] auto 版与 int 版的槽位间距完全一致
  [PASS] auto 与显式 int 混在同一帧内，每个槽位都是 4 字节

[4] 别名 vs 拷贝：地址给出确定答案
  &x = 0x61fd2c
  &y = 0x61fd28  (auto  y = x)
  &z = 0x61fd2c  (auto& z = x)
  [PASS] auto y = x 得到的是新对象（地址不同）
  [PASS] auto& z = x 是别名（地址相同）
  [PASS] 改 z 改到了 x，y 不变

[5] 存储期决定地址位置，auto 不参与决策
  全局 auto     &g_auto   = 0x40d018  (.data)
  文件内 static &g_static = 0x40d020  (.data)
  栈上 auto     &local    = 0x61fd24  (栈)
  堆上 auto     heap      = 0x1016f80  (堆)
  [PASS] new auto(5) 的类型是 int
  [PASS] 栈地址与堆地址不同（存储期不同）
  [PASS] 堆地址与静态区地址不同

[6] 有没有地址，取决于有没有被取地址 —— 与 auto 无关
  no_addr(7)  = 14   （从未取地址，优化后可能根本不占内存）
  has_addr(7) = 14   （取地址并逃逸，必须落在内存里）
  [PASS] 两种写法的结果一致，区别只在有没有地址
  [PASS] 逃逸后确实拿到了一个地址

[7] auto 本身不是类型，因此谈不上“它去分配地址”
  下面这些写法都编译不过（脚本里做的负例编译测试）：
    int n = sizeof(auto);      -> error: invalid use of 'auto'
    auto x;                    -> error: declaration of 'auto x' has no initializer
    struct S { auto m = 1; };  -> error: non-static data member declared with placeholder 'auto'
  auto 只能出现在【有初始化器、能推出类型】的声明里；
  它自己没有大小、没有地址、不产生任何运行时实体。

================ 结果 ================
全部检查通过（auto 不分配地址，且不改变地址分配规则）
